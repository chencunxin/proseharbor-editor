# Internationalization

Locales are handled by [i18next](https://www.i18next.com/) inside
`@proseharbor-editor/core`. All built-in menu labels, tooltips and placeholders
are translated, and you can register your own language at runtime.

## Built-in locales

| Code | Language         |
| ---- | ---------------- |
| `zh` | 简体中文（默认） |
| `en` | English          |
| `de` | Deutsch          |

::: warning Default language mismatch
The core initialises i18next with `lng: 'zh'`, while the Vue component's
`locale` prop defaults to `'en'`. As soon as a `ProseharborEditor` is mounted it
calls `changeLocale(props.locale)`, so **in Vue apps the effective default is
`en`**. Set `locale="zh"` explicitly if you want Chinese.
:::

## Choosing a locale (Vue)

```vue
<template>
  <ProseharborEditor v-model="content" locale="zh" :extensions="extensions" />
</template>
```

Changing the prop at runtime is reactive — the component watches it and calls
`changeLocale()` immediately (and on mount).

## Choosing a locale (core)

```ts
import { changeLocale } from '@proseharbor-editor/core'

changeLocale('en')
```

## API

```ts
import Locales, { addLocale, changeLocale, getLocale, t, te } from '@proseharbor-editor/core'
```

| Export         | Signature                                                    | Description                                                |
| -------------- | ------------------------------------------------------------ | ---------------------------------------------------------- |
| `Locales`      | `i18next` instance                                           | The underlying i18next instance (namespace `translation`). |
| `addLocale`    | `(lng: string, resources: Record<string, unknown>) => void`  | Adds (or merges) a resource bundle for a language.         |
| `changeLocale` | `(lng: string) => void`                                      | Switches the active language.                              |
| `getLocale`    | `(lng: string) => Record<string, unknown>`                   | Returns the resource bundle of a language.                 |
| `t`            | `(key: string, options?: Record<string, unknown>) => string` | Translates a key.                                          |
| `te`           | `i18next.exists`                                             | Whether a key exists.                                      |

`t()` is forgiving: when a key is missing it returns the **last segment** of the
key instead of the key itself — `t('fonts.Arial')` falls back to `Arial`.

```ts
t('bold') // '加粗' (zh) / 'Bold' (en)
t('sizes.tiny') // '极小' / 'Tiny'
```

## Adding a language

Merge your own bundle into an existing language, or register a brand new one:

```ts
import { addLocale, changeLocale } from '@proseharbor-editor/core'

addLocale('fr', {
  bold: 'Gras',
  italic: 'Italique',
  underline: 'Souligné',
  placeholder: 'Écrivez quelque chose…',
  fonts: {
    Arial: 'Arial',
  },
  sizes: {
    tiny: 'Minuscule',
    small: 'Petit',
    normal: 'Normal',
    large: 'Grand',
    huge: 'Énorme',
  },
})

changeLocale('fr')
```

::: tip
Bundles are merged (`addResourceBundle(..., deep = true, overwrite = true)`), so
you only need to provide the keys you want to override. Start from
`packages/core/src/locales/zh.json` (or `en.json`) to see every available key.
:::

## Translation key groups

| Group        | Example keys                                                                        |
| ------------ | ----------------------------------------------------------------------------------- |
| Text style   | `textStyle`, `background`, `color`, `fontFamily`, `fontSize`                        |
| Inline marks | `bold`, `italic`, `underline`, `strike`, `code`, `subscript`, `superscript`         |
| Link         | `link`, `linkPlaceholder`, `openInNewTab`, `unlink`                                 |
| Blocks       | `heading1`…`heading6`, `paragraph`, `blockquote`, `divider`, `codeBlock`            |
| Lists        | `bulletList`, `orderedList`, `taskList`                                             |
| Actions      | `indent`, `outdent`, `hardBreak`, `undo`, `redo`, `codeView`                        |
| Alignment    | `textAlign`, `alignLeft`, `alignCenter`, `alignRight`, `alignJustify`               |
| Table        | `table`, `tables.addColumnAfter`, `tables.mergeCells`, …                            |
| Image        | `image`, `insertImage`, `uploadImage`, `imageWidth`, `imageHeight`                  |
| Colors       | `colors.defaultColor`, `colors.standardColor`, `colors.recentUse`, `colors.palette` |
| Misc         | `placeholder`, `edit`, `copy`, `paste`, `cancel`                                    |

## Locale sub-path export

The locale entry point is published separately, which is handy for SSR or for
loading only the translation data:

```ts
import zh from '@proseharbor-editor/core/locales/zh.json'
```
