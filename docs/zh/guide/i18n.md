# 国际化

多语言由 `@proseharbor-editor/core` 内部的
[i18next](https://www.i18next.com/) 提供。所有内置菜单文案、提示与占位文本
均已翻译，你也可以在运行时注册自己的语言包。

## 内置语言

| 代码 | 语言             |
| ---- | ---------------- |
| `zh` | 简体中文（默认） |
| `en` | English          |
| `de` | Deutsch          |

::: warning 默认语言不一致
内核初始化 i18next 时用的是 `lng: 'zh'`，而 Vue 组件的 `locale` 属性默认为
`'en'`。组件挂载后会立即调用 `changeLocale(props.locale)`，所以**在 Vue 应用中
实际默认是 `en`**。需要中文请显式设置 `locale="zh"`。
:::

## 选择语言（Vue）

```vue
<template>
  <ProseharborEditor v-model="content" locale="zh" :extensions="extensions" />
</template>
```

该属性是响应式的——组件会监听它并立即（以及挂载时）调用 `changeLocale()`。

## 选择语言（内核）

```ts
import { changeLocale } from '@proseharbor-editor/core'

changeLocale('en')
```

## API

```ts
import Locales, { addLocale, changeLocale, getLocale, t, te } from '@proseharbor-editor/core'
```

| 导出           | 签名                                                         | 说明                                          |
| -------------- | ------------------------------------------------------------ | --------------------------------------------- |
| `Locales`      | `i18next` 实例                                               | 底层 i18next 实例（命名空间 `translation`）。 |
| `addLocale`    | `(lng: string, resources: Record<string, unknown>) => void`  | 新增（或合并）某语言的资源包。                |
| `changeLocale` | `(lng: string) => void`                                      | 切换当前语言。                                |
| `getLocale`    | `(lng: string) => Record<string, unknown>`                   | 获取某语言的资源包。                          |
| `t`            | `(key: string, options?: Record<string, unknown>) => string` | 翻译 key。                                    |
| `te`           | `i18next.exists`                                             | 判断 key 是否存在。                           |

`t()` 有兜底逻辑：当 key 不存在时返回 key 的**最后一段**，而不是整个 key——
`t('fonts.Arial')` 会回退为 `Arial`。

```ts
t('bold') // '加粗'（zh）/ 'Bold'（en）
t('sizes.tiny') // '极小' / 'Tiny'
```

## 新增语言

可以合并到已有语言，也可以注册全新语言：

```ts
import { addLocale, changeLocale } from '@proseharbor-editor/core'

addLocale('fr', {
  bold: 'Gras',
  italic: 'Italique',
  underline: 'Souligné',
  placeholder: '写点什么…',
  fonts: {
    Arial: 'Arial',
  },
  sizes: {
    tiny: 'Minuscule',
    small: 'Petit',
    normal: 'Normal',
    large: 'Grand',
    huge: 'Énorme',
  },
})

changeLocale('fr')
```

::: tip
资源包是**合并**写入的（`addResourceBundle(..., deep = true, overwrite = true)`），
因此只需提供你想覆盖的 key。可先参考
`packages/core/src/locales/zh.json`（或 `en.json`）查看全部可用 key。
:::

## 文案分组

| 分组     | 示例 key                                                                            |
| -------- | ----------------------------------------------------------------------------------- |
| 文字样式 | `textStyle`、`background`、`color`、`fontFamily`、`fontSize`                        |
| 行内标记 | `bold`、`italic`、`underline`、`strike`、`code`、`subscript`、`superscript`         |
| 链接     | `link`、`linkPlaceholder`、`openInNewTab`、`unlink`                                 |
| 块       | `heading1`…`heading6`、`paragraph`、`blockquote`、`divider`、`codeBlock`            |
| 列表     | `bulletList`、`orderedList`、`taskList`                                             |
| 操作     | `indent`、`outdent`、`hardBreak`、`undo`、`redo`、`codeView`                        |
| 对齐     | `textAlign`、`alignLeft`、`alignCenter`、`alignRight`、`alignJustify`               |
| 表格     | `table`、`tables.addColumnAfter`、`tables.mergeCells` 等                            |
| 图片     | `image`、`insertImage`、`uploadImage`、`imageWidth`、`imageHeight`                  |
| 颜色     | `colors.defaultColor`、`colors.standardColor`、`colors.recentUse`、`colors.palette` |
| 其他     | `placeholder`、`edit`、`copy`、`paste`、`cancel`                                    |

## 子路径导出

语言包入口单独发布，便于 SSR 或只加载翻译数据：

```ts
import zh from '@proseharbor-editor/core/locales/zh.json'
```
